# 界面入口与 Files 页签

English: [ui-entries.en.md](./ui-entries.en.md)

除了命令，附加根也可以从界面管理。侧栏入口和 Files 页签打开的是同一份登记数据，改动会立即反映到命令与模型侧。

## 侧栏与新会话页

- 侧栏底部的 **工作区目录**（英文界面为 **Folders**）打开「工作区目录」对话框：添加或移除根、编辑显示别名与访问权限、逐根开关 Skills、复制路径、在文件管理器中显示、重试，以及打开 Worktree 建议。
- DSH `0.2.1-alpha.3` 起，新会话页工作区行右端也有同一入口。它没有下拉箭头，窄窗口只显示图标；首条消息发出后这个入口消失，侧栏入口仍然保留。

## 工作区行菜单

工作区行的 `…` 菜单和右键菜单中都有 **管理工作区目录…**：

- 当前会话已经属于该工作区：直接打开对话框。
- 当前会话属于别的工作区：先打开或复用该工作区的空白页，确认它成为当前会话后再打开对话框。

## Files 页签

- 头部根选择器在主根与附加根之间切换，旁边仍显示所选根的完整路径。
- 选中附加根后，目录树、打开文件、在应用中打开、右键菜单、自动刷新和工作区搜索都按该根工作。
- 切回主根即恢复原生视图。

如果另一个插件接管了整个 Files 页，根选择器会暂时不可用；此时仍可以从侧栏「工作区目录」管理根，接管结束后恢复。
