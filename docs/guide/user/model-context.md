# 模型上下文

English: [model-context.en.md](./model-context.en.md)

插件不新增工具；它把工作区拓扑和附加根的指令文件提供给模型，让 Agent 知道哪些目录可以用。

## 工作区拓扑

主根与附加根的可用目录、访问方式会注入系统提示词；授权变化时信息随之更新。模型不需要额外的内省工具就能知道当前能读写哪些目录。

## 指令文件

附加根自己的 `AGENTS.md` / `CLAUDE.md` 也会进入模型上下文：

- 根目录顶层的文件在会话第一步之前注入。
- 子目录里的文件在本会话成功执行过 `read` / `write` / `edit` 并触碰该目录之后注入；失败的操作不算。
- 投递状态保存在进程内，恢复会话后可能再次告知。
- 主根与用户全局的指令链由 DSH 自身负责，插件不会重复注入。

指令属于用户上下文，不是系统授权；它不能让 Agent 获得未授予的写权限。
