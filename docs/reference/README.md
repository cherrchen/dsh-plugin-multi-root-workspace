# 技术参考（Reference）

English: [README.en.md](./README.en.md)

## 这里存放什么

稳定的参考资料，例如：

- configuration reference；
- API reference；
- schemas；
- protocols；
- file formats。

## 不应该存放什么

- Proposal 或 Target Design；
- brainstorming 与临时讨论；
- 开发计划；
- 尚未确定的设想。

这里只放已经确定、相对稳定的事实性参考内容。
