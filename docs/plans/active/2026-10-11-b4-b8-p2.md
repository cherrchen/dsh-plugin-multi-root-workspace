# B4–B8：第二期 P2 加固（per-root / per-tool 权限、mutation 前重分类、根上限、provider 冲突、平台感知提示词）

## Goal

把第二期 P2 的五项加固落地为 fail-closed 的授权模型：根自带访问级别、按工具收窄写权限、mutation 永远基于 fresh 分类、根数量有上界、外来 provider 冲突响亮失败，并让模型看到的拓扑如实陈述这些事实。

## Preconditions

- 基线 `a385f06`（main，含 B1–B3 与 DSH 0.2.1 适配）。
- 已确认事实：全部支持版本（`0.1.5-rc.2` … `0.2.1-alpha.2`）经 `ctx.waterfall(carrier, 'tools/execute', exec, …)` 派发工具，`exec.name` 是注册解析后的工具名；`src/compat/tool-context.ts` 的 `aroundTool` 已挂同一 seam。
- cordis 实测：同 service key 二次 `provide` 同步抛错（先提供者胜出）；`notify` 使依赖 fiber 在替换时重启。
- JSON storage 对 domain version 严格相等校验 ⇒ 持久化布局不可升版本。

## Design

| 项 | 决策 | ADR |
|---|---|---|
| B4 per-root + per-tool 访问 | `recordedPath` = 可写 grant、`readOnlyRecordedPath` = 只读 grant（v1 单布局，降级 fail closed 为 invalid）；`writableRoots` = rw 成员 ∩ 工具 cap，ALS 沿 `tools/execute` 携带，dispatch 外配置非空即封顶 | [ADR-0013](../../decisions/ADR-0013-per-root-and-per-tool-access.md) |
| B5 mutation 前重分类 | 每个 mutation 的 serialize job 第一步 reclassify；revive 只看 fresh 分类 | [ADR-0004 修订](../../decisions/ADR-0004-root-registry-persistence-and-validation.md)、[ADR-0014](../../decisions/ADR-0014-root-limit-and-provider-conflict.md) |
| B6 根上限 | `maxAdditionalRoots` 默认 16、顶 64；按全部存储记录计数；超限存量照授只拒新增；非法配置 fail closed | [ADR-0014](../../decisions/ADR-0014-root-limit-and-provider-conflict.md) |
| B7 provider 冲突 | Symbol 品牌 + `multi-root-providers` 门禁行；外来 `ctx.fs`/`ctx.sandbox` 下行不存在 ⇒ 空 scope | [ADR-0014](../../decisions/ADR-0014-root-limit-and-provider-conflict.md) |
| B8 平台感知提示词 | `renderWorkspaceRootsContext` 纯函数化（platform/mode/roots/cappedTools）；只列可用成员；win32 附带 restricted-token partial-enforcement 与读不受限说明 | [ADR-0013](../../decisions/ADR-0013-per-root-and-per-tool-access.md) |

- **本机跳过**：bwrap / Landlock 真实执行行存在但本机无 runner；`tests/windows-native.e2e.ts`（win32-gated）跳过。

## Limitations

- 已运行进程保留启动时 token/scope 快照（ADR-0012），cap 与 access 变更不回收。
- `toolAccess` 只收窄附加根写权限；主根与上游行为不变。
- read-only 是写授权缺省，不是读 confinement。
- dispatch 外的操作在 `toolAccess` 非空时一律按封顶处理（刻意的偏严）。
- 已知 CI 抖动（非本批回归）：Windows 腿上既有 B1–B3 用例 "refuses a root the caller does not own" 的 icacls 夹具搭建偶发 `Access is denied`（`0.1.6-alpha.2` 腿一次失败、重跑即过，其余 10 腿全过）；fixture setup 的环境问题，非授权语义。
